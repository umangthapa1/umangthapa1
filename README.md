# 🚀 Currently Building

## 🧠 MINDBASE

My main project right now.

**MINDBASE** is an AI-powered personal workspace designed to bring conversations, documents, notes, email, memory, research, and tasks into one intelligent interface.

Instead of jumping between different productivity tools, you can simply talk to MINDBASE.

```text
                    MINDBASE
                       │
        ┌──────────────┼──────────────┐
        │              │              │
      Chat          Memory        Documents
        │              │              │
      Notes          Email         Research
        │              │              │
      Tasks         Calendar       AI Search
        │              │              │
        └──────────────┼──────────────┘
                       │
                  AI Workspace
```

You can ask:

```text
"Summarize my latest emails."

"What tasks are due tomorrow?"

"Find my notes about FastAPI."

"Summarize this PDF."

"Remember this for later."

"Research local LLMs."
```

The goal is to make AI feel less like a chatbot and more like an **intelligent layer over your personal workspace**.

MINDBASE also focuses heavily on **local-first AI**, using technologies such as Ollama to run models locally.
